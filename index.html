PhishyEmail

Developed PhishyEmail, a Chrome extension and local backend that detects phishing emails in real time as users read them in Gmail and Outlook web. Designed a heuristic scoring engine analyzing sender legitimacy, URL structure, and message content, cross-referencing links against a live threat-intelligence feed (URLhaus) to flag lookalike and punycode domains, spoofed display names, and mismatched link text/href pairs. Prioritized user privacy by running all analysis locally, with the only external call being a daily threat-feed sync. Implemented a Manifest V3 content-script pipeline to extract and fingerprint open emails, and a FastAPI backend with a SQLite-backed verdict cache, rendering results as an inline warning banner using JavaScript, Python, and FastAPI.

Python, FastAPI, JavaScript, SQLite
